# DIY Stuff carousel originals

Downloaded on 2026 from [Marco van Nieuwenhoven's Estimote UWB teardown](https://diystuff.nl/embedded/estimote-uwb-location-beacon-teardown/). Reference for UWB I1.2 hardware, not a photograph of our F3.3 unit.

Carousel order:

1. `1TopComponents.png`: photograph with components and numbering.
2. `1Top.png`: drawing of the top copper and footprints.
3. `2Inner.png`: first inner layer.
4. `3Inner.png`: second inner layer.
5. `4Bot.png`: bottom layer.

The original bytes were preserved, with no rotation, cropping, resizing or conversion. `manifest.json` records URL, dimensions, colour mode, size and SHA-256.

For future overlay: verify registration using vias, holes and outline; do not assume an exact match between photograph and drawings. The layer images use a common orientation in the publication; verify it using references before mirroring the bottom side. The proposed correspondence with our A–H map requires rotating 90° clockwise, without mirroring. Crossings in projection do not prove continuity between layers.
