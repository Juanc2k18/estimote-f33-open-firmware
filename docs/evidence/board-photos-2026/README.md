# Estimote F3.3 board photographs · 2026

Three owner-supplied photographs replace the earlier general-view photo in the
main README. The owner retains the HEIC originals outside this repository.
Only the cropped JPEG copies are published.

| Published photograph | View |
|---|---|
| `estimote-f33-front.jpg` | Component side, nRF52832 marking and programming pads |
| `estimote-f33-front-angle.jpg` | Component side from a second angle |
| `estimote-f33-battery-side.jpg` | Battery contacts, four-CR2477 legend and F3.3 model label |

Processing: HEIC-to-JPEG conversion and rectangular crops around the device,
with a small surrounding margin to preserve the complete board and contacts.
The Display P3 source colors were converted to sRGB for web display. No
components, markings or wires were generated, removed or retouched.

All embedded EXIF, GPS, XMP, IPTC, comments and color-profile metadata were
removed from the published JPEGs with ExifTool. Verification found no embedded
capture time, location, camera identifiers or other descriptive metadata.
File-system dates are not embedded photo metadata and are not stored as image
attributes by Git. The visible manufacturing date on the board label is part
of the photograph, not hidden metadata.

These photographs document appearance. They do not add electrical continuity,
voltage or sensor-function measurements. See the [guide](../../guide-f33.md)
for the validated connections and open items. `SHA256SUMS` checks the published
copies and this description.
